Why a desktop app

Running locally means it can do the things a web page cannot: reach your own files and hardware, keep working while the network is down, and hold data on your machine instead of someone else's.

What to expect

Beta builds are rough. Features change, files move, and something will be broken at some point. If that is not what you want from software, wait for the stable release.

How the beta works

Every Aether account can ask for the Tester role. We hand it out by hand, so it may take a day or two. Testers also get the Beta area of the site and a direct line for feedback.

While you wait

The studio is still taking website and Discord bot work, and those were never blocked on this. Have a look at the shop if you need something built properly.

This page is configuration-driven. The name, tagline, platform, version, size, checksum and download link all come from one block in public/aether-config.js — so publishing a build is a single edit, and nothing here invents a version number or a file that does not exist.
