Hosting guidance

For small static websites, we recommend Netlify or GitHub Pages. For sites with admin logins or backend features, Cloudflare or a suitable managed host is a better fit. We can also point you toward domain providers such as Prepaid Hoster, Cloudflare or Hostinger.

Important — please read

  • Hosting is not included
  • Domain is not included
  • Backend is not included
  • Database systems are not included
  • Websites are delivered as source files
  • Customer is responsible for hosting the website
  • Prices are starting prices
  • Custom websites are priced according to requirements
  • Communication via Discord or Email
  • Payment via Crypto — Bitcoin, Litecoin, Ethereum (NOWPayments)

We don't advertise “+ Database” or “+ Hosting” as paid add-ons — because we don't provide them. What you pay for is design + code you own.
