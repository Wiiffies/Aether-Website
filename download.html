What changed

  • One Windows executable with the .NET runtime included.
  • WebView2 is checked on first launch and installed if it is missing.
  • 99 FastFlag presets, with backup and rollback for ClientAppSettings.json.
  • Multiple clients, version pinning, and the six-panel overlay.

Before you run it

This build is not code-signed. Windows SmartScreen may warn on first launch. If Windows holds the file, open its properties and choose Unblock.

Keep a copy of your Roblox client settings if you use other tools that write to the same file.

Requirements

  • Windows 10 or 11, 64-bit.
  • A Roblox client installed under %LOCALAPPDATA%\Roblox.
  • Microsoft Edge WebView2. Aether offers to install it if it is missing.
